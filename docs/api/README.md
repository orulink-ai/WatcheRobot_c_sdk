# API 使用指南 / API guides

从[功能指南](../features.md)选择要调用的接口。各页面说明最短调用流程、参数、数据有效期、错误处理和完整示例入口。

应用接口位于 `watcher_hw_*` 组件；视觉推理使用 `hal_camera` 进阶接口。各页提供对应头文件和组件链接，便于查看完整声明。

首次运行见[上手教程](../getting-started_zh.md)，可运行工程见[示例目录](../../examples/README.md)。

Use the [feature guide](../features.md) to find an API. Each page covers the call sequence, parameters, data lifetime, errors and runnable examples, with links to headers for full declarations.

Application APIs live in the `watcher_hw_*` components; vision inference uses the advanced `hal_camera` API. For setup, follow the [first-run tutorial](../getting-started.md); complete projects are listed under [examples](../../examples/README.md).
